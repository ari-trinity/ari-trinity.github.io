# Loloved

Loloved is a simple and easy to use application for friends and family. Whether they're having a bad day or just need a smile – Loloved is personalized for them. It features a "Hype Me Up" and "Make Me Laugh" button, where the user can generate a variety of compliments and jokes by clicking the buttons. The "Just for You" button is the final page that provides a motivating message using the name of the user to be more personable.

## Usage / Examples

1. Open the application in your preferred browser.
2. Type your first name.
3. Choose whether or not you want a hype-up, laugh, or both! You can easily generate a new one by clicking the **Hype Me Up** and **Make Me Laugh** buttons again.
5. Once you've read through a few, you'll notice there is a **Just for You** button. A user can go onto this page to receive a motivational message and some much-needed inspiration. If you'd like to start over using a different name, click the **start over** button and it will direct you back to the main page.
6. If your name is not implemented into the application, the compliments and jokes will not be personalized and tailored for you. If you'd like to change that, email me at [aritrin.business@gmail.com](mailto:aritrin.business@gmail.com) and I will get back to you within 24 hours.

## Installation

To run this project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/ari-trinity/ari-trinity.github.io.git
   ```

2. **Navigate into the project folder**
   ```bash
   cd ari-trinity.github.io
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```
